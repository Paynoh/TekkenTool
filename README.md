## How to use

Inject the DLL into `Polaris-Win64-Shipping.exe` using a DLL injector. I recommend [Xenos](https://github.com/DarthTon/Xenos).

Press **F6** to toggle the menu and **Delete** to unload the tool.

I haven't experienced any crashes, but they may occur because the tool hooks several game functions.
